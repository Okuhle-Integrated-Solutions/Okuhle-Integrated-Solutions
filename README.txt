FREE HOSTING WITH GITHUB PAGES
1. Sign in or create a GitHub account.
2. Create a PUBLIC repository named okuhleintegratedsolutions-website.
3. Upload index.html, styles.css and script.js to the top level of the repository.
4. Open repository Settings > Pages and publish from the main branch, root folder.
5. Add okuhleintegratedsolutions.co.za under the Custom domain setting and save.
6. Configure the domain's DNS records at your registrar using GitHub's current official instructions:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
7. GitHub currently documents these A-record addresses for the root domain:
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
For www, add a CNAME pointing to YOUR-GITHUB-USERNAME.github.io.
8. Wait for DNS propagation and enable Enforce HTTPS in GitHub Pages when it becomes available.

Do not change DNS until your GitHub Pages repository and custom-domain setting are ready. DNS changes can take up to 24 hours.
